# 🛒 Mini Amazon

A responsive **Mini Amazon e-commerce website** developed using **HTML, CSS, JavaScript, and Bootstrap 5**. The project provides a simple Amazon-inspired shopping interface with product cards, offers, navigation, search UI, and a responsive layout.

## 📌 Project Overview

**Mini Amazon** is a frontend web development project designed to demonstrate the use of HTML, CSS, JavaScript, and Bootstrap to create a modern and responsive e-commerce website.

The website includes a navigation bar, search interface, hero section, promotional offer banner, featured products, special offers, and footer.

## ✨ Features

* 🏠 Responsive navigation bar
* 🔍 Product search interface
* 🛍️ Featured products section
* 💰 Product pricing and Buy Now buttons
* 🔥 Promotional offer banner
* 🎁 Special offers section
* 📱 Responsive design using Bootstrap
* 🎨 Custom CSS styling
* ⚡ JavaScript-based welcome and browser interaction
* 🖼️ Product images and Amazon-inspired branding
* 📱 Mobile-friendly Bootstrap layout

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Custom styling and design
* **JavaScript** – Interactive functionality
* **Bootstrap 5** – Responsive layout and UI components

## 🛒 Products

The website currently displays **8 featured product cards**, with different prices and product images.

Each product card contains:

* Product image
* Product name
* Product price
* Buy Now button

## 🎯 Special Offers

The project includes a dedicated Special Offers section featuring:

* **50% Offers**
* **Buy 1 Get 1 Free**
* **Free Gift**

## 📱 Responsive Design

Bootstrap's responsive grid system is used to make the product layout adapt to different screen sizes.

The product cards use responsive columns such as:

```text
Large screens  → 4 products per row
Medium screens → 2 products per row
Small screens  → Responsive layout
```

## ⚡ JavaScript

JavaScript is used to provide browser-based interactions, including a welcome alert and browser detection.

## 🚀 How to Run

1. Download or clone this repository.

2. Open the project folder in **Visual Studio Code**.

3. Open `index.html`.

4. Run the project using **Live Server** or open the HTML file directly in a web browser.
